# Creator Analytics Bot Terms of Service

Last updated: August 2026

## Overview

Creator Analytics Bot is a personal analytics application that helps creators monitor and analyze their social media performance.

The application may connect to approved social media platforms to provide analytics, tracking, reports, and growth insights.

## Use of the Application

By using Creator Analytics Bot, you agree to:

- Only connect accounts that you own or have permission to access.
- Use the application only for legitimate analytics purposes.
- Keep your account credentials and access information secure.
- Follow the rules and policies of connected platforms.

## Data Usage

Creator Analytics Bot only uses data required to provide analytics features.

Data may include:

- Profile statistics
- Video performance statistics
- Growth metrics
- Historical analytics data

Data is used only to provide analytics functionality.

## Data Sharing

Creator Analytics Bot does not:

- Sell user data
- Share user data with third parties for advertising
- Use user data for purposes unrelated to analytics

## Account Access

Users can revoke application access at any time through the connected platform's account settings.

## Availability

The application is provided as-is. Features may change, improve, or become unavailable due to changes in third-party platforms or services.

## Third-Party Services

Creator Analytics Bot may use third-party platforms including:

- YouTube
- TikTok
- Discord

Each platform has its own terms and policies that users must follow.
